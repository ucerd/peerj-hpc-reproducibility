# Source-specific Namal HPC context

This package includes **contradictory source descriptions** without inferring a historical upgrade sequence. The 2026-09 repository profile reports 20 nodes, 40 RTX 4070 Ti accelerators, '1,600 cores', 5 TB RAM and an unspecified low-latency switched fabric; it does not distinguish physical cores from threads. A separately supplied 18-page COTS technical manuscript reports 20 nodes, 800 **physical** cores / 1,600 hardware threads, 40 RTX 4090 accelerators, 5 TB RAM and 10 GbE. The uploaded sources do not prove whether these represent a version change, a different installation or a reporting inconsistency. See `data/cluster_configuration_sources.csv`.

None of these hardware snapshots was used to derive the university design-framework's Table 3 illustrative capacity numbers. For a validated current configuration, a dated equipment inventory, software/network inventory, change log and operator sign-off are necessary. Research service outcomes and partner-assistance claims also require separate documentation.
