# Namal HPC public implementation context

The Namal Supercomputing Facility is included in this repository as
**contextual implementation evidence only**. It is not the empirical dataset
used to derive the manuscript's illustrative sizing examples, and no
institutional outcome claim is calculated from these values.

The operator-confirmed GPU, RAM, and network values above supersede older
conflicting summary values in earlier public material.

## Methodological boundary

The manuscript develops a generalizable design framework. The Namal facility
demonstrates that the service concepts discussed in the paper are implementable
in an operational university environment. It is **not** used as a statistical
validation sample, and the repository does not republish proprietary
institutional KPI/outcome data.

Public site: https://caid.namal.edu.pk/
