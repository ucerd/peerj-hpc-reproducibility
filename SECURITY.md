# Security and publication-safety policy

This is a public reproducibility repository. It intentionally excludes:

- passwords, tokens, private keys, and credentials;
- private IP addresses;
- production hostnames and per-node NIC mappings;
- firewall rules;
- production `slurm.conf`, authentication keys, or scheduler secrets;
- user account lists or personally identifiable data.

The Slurm examples are templates. Site-specific partitions, QoS, account names,
module names, storage paths, and network interfaces should be supplied locally.
